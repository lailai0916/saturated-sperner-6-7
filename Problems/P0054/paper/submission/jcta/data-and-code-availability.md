# Data and code availability package

## 1. Ready-to-paste statement

This work is theoretical and does not generate or analyse empirical datasets.
The supporting artifact package contains the Lean 4 formalization, exact
search programs, construction verifiers, certificate generators, CNF
instances, DRAT proofs, verification scripts, manifests, checksums, tests,
and locked dependency metadata. Source and release materials are available
from [GitHub release `v1.0.0`](https://github.com/lailai0916/saturated-sperner-6-7/releases/tag/v1.0.0).
The immutable archive is available from
[Zenodo](https://doi.org/10.5281/zenodo.21679078).

The statement is ready for submission. The GitHub release and Zenodo record
resolve publicly and refer to the same fixed archive.

## 2. Public release verification

1. GitHub tag and release `v1.0.0` are public with the full archive, its
   SHA-256 sidecar, and three final PDFs.
2. Zenodo record `21679078` is public under DOI
   `10.5281/zenodo.21679078`.
3. The GitHub archive SHA-256 and the Zenodo archive MD5 match the fixed local
   payload.
4. The public archive contains the license, citation metadata,
   software/environment versions, verification entry points, and the nine
   archived CNF/DRAT pairs listed by the release manifest.
5. Any future payload change requires a new version and fresh checksums.
