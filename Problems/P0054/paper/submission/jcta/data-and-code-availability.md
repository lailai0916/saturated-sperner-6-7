# Data and code availability package

## 1. Final statement

This work is theoretical and does not generate or analyse empirical datasets.
The supporting artifact package contains the Lean 4 formalization, exact
search programs, construction verifiers, certificate generators, CNF
instances, DRAT proofs, verification scripts, manifests, checksums, tests,
and locked dependency metadata.  This revision is available from [GitHub
release `v1.1.2`](https://github.com/lailai0916/saturated-sperner-6-7/releases/tag/v1.1.2).
Its immutable Zenodo archive has DOI
[`10.5281/zenodo.21770438`](https://doi.org/10.5281/zenodo.21770438).

## 2. Repository and identifier verification

1. The artifact is the immutable formal-source, certificate, and replay
   snapshot cited by the paper.
2. GitHub release `v1.1.2` and Zenodo version DOI `10.5281/zenodo.21770438`
   are public and resolving.
3. The public archive includes the license, citation metadata,
   software/environment versions, verification entry points, and the nine
   archived CNF/DRAT pairs listed by the release manifest.
4. The present release synchronizes the professionally typeset manuscript
   with the unchanged Lean source, certificates, manifests, and executable
   results.
5. The submission-output checksum is recomputed after the rendered files are
   regenerated.
